Snowfall event verification

All times UTC. Separate reports and model runs remain separate. Forecast windows may differ from observation windows. Nearby reports can share an archive point.

QC'ed storm totals are compared with explicitly selected forecast windows. Observation accumulation boundaries are unspecified; report valid dates are not treated as accumulation endpoints.

Triangles on maps/scatterplots represent snow-depth change, not a direct new-snow measurement.

Maps use report coordinates. Nearby archive-point distances are listed in individual report graphics.

Map view: Anchorage. Zoom changes the map view only; charts and percentile statistics still use all selected reports, and map colors retain the configured range. Filter stations/reports to change the verification sample.

No NBM percentile comparisons are present in this CSV. Check the NBM source columns and --nbm-init, then rerun verification.
