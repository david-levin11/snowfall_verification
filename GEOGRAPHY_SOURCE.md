# Bundled map geography

`ne_50m_land.geojson` is the Natural Earth 1:50m land dataset, retrieved from:
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_land.geojson

Natural Earth data are in the public domain:
https://www.naturalearthdata.com/about/terms-of-use/

The plotting code uses the land polygon exterior rings as background geography, with no online services at runtime. Coastline detail is limited by this dataset's scale.
